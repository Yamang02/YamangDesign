# P01: Scope and Token Mapping

## 목표
- 타 어드민 레이아웃을 참고해 Yamang으로 옮길 **블록 단위 범위**가 확정된다.
- 블록별로 Yamang **기존 컴포넌트 재사용** vs **신규 구현** vs **보류**가 구분된다.
- Admin 화면에서 관측되는 색·간격·타이포가 **`--ds-*` / `--ui-*` 매핑 초안**으로 정리되고, 토큰 갭(신규 토큰 필요 여부)이 식별된다.
- **antd 비도입·스펙 재작성** 원칙이 본 Phase와 Epic Readme 간에 모순 없이 기록된다.

## 구현 상세
- 참고한 타 어드민 레이아웃에서 `AdminLayout`, `Sidebar`, `Header`, 자주 쓰는 `templates`·페이지 패턴을 검토해 **이식 블록 목록**을 만든다.
- Yamang의 `src/app/components`, `src/domain/tokens`, 레이아웃 관례와 **대응 표**를 작성한다.
- 인라인 hex·고정 px는 나열하되, Yamang 정책상 **최종 구현은 토큰 우선**임을 표에 반영한다.
- Table·DatePicker·차트 등 **고복잡도** 항목은 P01에서 범위(자체 단순화 / 후속 Phase / 예외 검토)를 한 단락으로 박는다.
- 문서만 갱신하는 Phase이므로 **코드 변경은 필수 아님**. 다만 매핑 결과에 따라 Epic Readme `특이점`을 갱신한다.

## 체크리스트
- [ ] 이식 블록 목록(레이아웃 셸·사이드 네비·헤더·콘텐츠 패딩·표/필터·모달 등)이 본 문서에 정리되어 있다.
- [ ] 블록별 Yamang 대응(기존 컴포넌트 경로 / 신규 / 보류)이 표로 명시되어 있다.
- [ ] 색·간격·타이포에 대한 토큰 매핑 초안 또는 신규 토큰 필요 목록이 정리되어 있다.
- [ ] antd 미도입·Ant 자산 미복제 원칙이 Epic Readme와 본 Phase에 일치하게 기록되어 있다.
- [ ] 고난도 위젯·차트의 후속 처리 방향이 한 단락 이상으로 결정되어 있다.
