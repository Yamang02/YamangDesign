# P03: Admin Shell Layout

## 목표
- Admin 셸의 3개 핵심 레이아웃 블록(사이드바, 헤더, 메인 콘텐츠)이 Yamang 토큰 기반으로 렌더된다.
- 접힘/펼침 사이드바와 헤더 토글 인터랙션이 동작하고, 콘텐츠 영역 패딩/최소높이 규칙이 고정된다.
- P04에서 복합 블록을 붙일 수 있는 셸 골격(슬롯/레이아웃 컨트랙트)이 준비된다.

## 구현 상세
- P02에서 만든 `AdminSidebarItem`, `AdminTopBarActions`를 조합해 `AdminSidebarNav`, `AdminHeaderBar`를 구현한다.
- 신규 `AdminShellLayout`에서 `sidebar`, `header`, `content` 슬롯을 받아 화면 골격을 구성한다.
- 레이아웃 스타일은 `--ds-*` + `--admin-*` 토큰만 사용한다.
- 진입점은 기존 Context/Lab 구조를 따라 별도 데모 섹션 또는 라우트로 연결한다.

### 반영 파일
- 컴포넌트:
  - `src/app/components/AdminShellLayout/*`
  - `src/app/components/AdminHeaderBar/*`
  - `src/app/components/AdminSidebarNav/*`
- 데모 진입점:
  - `src/app/pages/context/AdminShell.tsx`
  - `src/app/pages/context/AdminShell/AdminShellContext.tsx`
- 네비/라우팅 연결:
  - `src/app/config/nav-categories.ts`
  - `src/App.tsx`

## 체크리스트
- [x] `AdminShellLayout`이 사이드바/헤더/콘텐츠 슬롯 기반으로 동작한다.
- [x] 사이드바 접힘/펼침 상태와 활성 메뉴 상태가 시각적으로 구분된다.
- [x] 헤더 우측 액션(`AdminTopBarActions`)이 유저/역할/로그아웃 상태를 표시한다.
- [x] 콘텐츠 영역 패딩/최소높이 규칙이 토큰 기반으로 적용된다.
- [x] P04에서 재사용할 레이아웃 컨트랙트(필수 props)가 문서나 타입으로 확인 가능하다.
