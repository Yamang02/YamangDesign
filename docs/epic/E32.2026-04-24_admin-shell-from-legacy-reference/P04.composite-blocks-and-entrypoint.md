# P04: Composite Blocks and Verification Entrypoint

## 목표
- Admin 셸 위에서 복합 UI 블록(테이블/필터/모달)이 하나의 흐름으로 결합된다.
- 검증 진입점(Context 또는 Lab)에서 실제 상호작용(필터 변경, 모달 열기, 행 선택)을 확인할 수 있다.
- P01에서 보류한 고복잡도 범위(가상 스크롤, 고급 DatePicker, 차트)가 제외 범위로 명시된다.

## 구현 상세
- `AdminFilterBarBase` + 테이블 프리뷰 컴포넌트를 결합한 `AdminTableTemplate` 1차 버전을 구현한다.
- `AdminModalTemplate`를 추가해 확인/취소/로딩 상태의 공통 모달 패턴을 제공한다.
- `AdminShell` 데모에 테이블+필터+모달 상호작용 샘플을 연결한다.
- 제외 범위(가상 스크롤/고급 DatePicker/차트)는 문서와 체크리스트에 유지한다.

### 반영 파일
- `src/app/components/AdminTableTemplate/*`
- `src/app/components/AdminModalTemplate/*`
- `src/app/pages/context/AdminShell/AdminShellContext.tsx`

## 체크리스트
- [x] `AdminTableTemplate`가 필터/페이지네이션/정렬의 기본 조합을 제공한다.
- [x] `AdminModalTemplate`가 열림/닫힘/로딩 상태를 토큰 기반 스타일로 제공한다.
- [x] `AdminShell` 진입점에서 테이블/필터/모달 상호작용이 확인된다.
- [x] 제외 범위(가상 스크롤/고급 DatePicker/차트)가 문서에 유지된다.
