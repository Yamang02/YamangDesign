# Product Documents

> 상태: 확정
> 문서 성격: 디렉터리 안내
> 최종 수정: 2026-07-18

이 디렉터리는 ClipPro의 제품 정의, 사용자 가치, 제품 원칙, 수익 모델 및 장기 확장 방향을 기록한다.

제품 문서는 특정 구현 에픽보다 상위의 판단 기준으로 사용한다. 기능을 설계하거나 구현할 때 제품 문서와 충돌하는 결정이 필요하다면, 구현을 우선하기 전에 제품 문서의 변경 여부를 검토한다.

## 문서 구분

- `docs/product/`: 제품 정의, 사용자 가치, 정책, 비즈니스 모델, 장기 방향
- `docs/architecture/`: 제품 방향을 실현하기 위한 기술 구조와 트레이드오프
- `docs/epic/`: 기간과 완료 조건이 있는 개발 작업
- `docs/archive/`: 종료되었거나 더 이상 현재 기준이 아닌 작업 기록

## 상태 표기

- **확정** — 현재 제품 판단의 기준으로 사용한다.
- **방향** — 우선적으로 지향하지만 구현 및 검증에 따라 변경할 수 있다.
- **가설** — 사용자 검증 또는 운영 데이터가 필요한 판단이다.
- **미정** — 아직 결정하지 않았다.
- **보류** — 현재 범위에서 구현하지 않으며 미래 검토 대상으로 남긴다.
